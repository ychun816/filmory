# resources

Curated by me and ChatGPT 🔥
Here’s the learning path I recommend for Docker + Kubernetes 👇

1️⃣ Docker fundamentals

• freeCodeCamp Docker course:
https://www.youtube.com/watch?v=rjjES5IsPdg

• Official Docker workshop:
https://docs.docker.com/get-started/workshop/

• Docker Compose tutorial:
https://docs.docker.com/compose/gettingstarted/


2️⃣ Main Kubernetes course

• Linux Foundation — Introduction to Kubernetes (LFS158):
https://training.linuxfoundation.org/training/introduction-to-kubernetes/


3️⃣ Official Kubernetes tutorial

• Kubernetes Basics:
https://kubernetes.io/docs/tutorials/kubernetes-basics/


4️⃣ Hands-on practice

• KodeKloud Kubernetes Challenges:
https://kodekloud.com/courses/kubernetes-challenges

• KodeKloud free labs:
https://kodekloud.com/studio/labs/kubernetes

• Killercoda Kubernetes playground:
https://killercoda.com/playgrounds/scenario/kubernetes

• CKA practice scenarios:
https://killercoda.com/cka


5️⃣ Small Kubernetes project

• Official frontend + Redis guestbook project:
https://kubernetes.io/docs/tutorials/stateless-application/guestbook/


6️⃣ Advanced topics

• Helm: https://helm.sh/docs/intro/quickstart/

• RBAC: https://kubernetes.io/docs/reference/access-authn-authz/rbac/

• Health probes: https://kubernetes.io/docs/tasks/configure-pod-container/configure-liveness-readiness-startup-probes/

• CPU and memory limits: https://kubernetes.io/docs/concepts/configuration/manage-resources-containers/

• NetworkPolicies: https://kubernetes.io/docs/concepts/services-networking/network-policies/

• StatefulSets: https://kubernetes.io/docs/concepts/workloads/controllers/statefulset/

• Troubleshooting: https://kubernetes.io/docs/tasks/debug/debug-application/


Best order:

Docker course → Docker workshop → LFS158 → Kubernetes Basics → hands-on labs → personal project → Helm and advanced topics 🚀
